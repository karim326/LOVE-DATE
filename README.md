# دعوة إلى موعد 🌸

تجربة تفاعلية من أربع خطوات بدعوة رومانسية، بتصميم باستيل هادئ وبطاقة بيضاء مستديرة في المنتصف.

## ما يوجد داخل المشروع

| الملف | الدور |
| --- | --- |
| `index.html` | بنية الصفحة والخطوات الأربع والعلامة المائية |
| `styles.css` | التصميم الباستيل، الخلفيات المتدرجة، الحركات، والتجاوب مع الهاتف |
| `app.js` | التنقل، التقويم، اختيار الطعام، هروب زر «لا»، وإعادة الضبط |
| `serveur-local.ps1` | خادم محلي بسيط بدون Node.js أو Python |

## التشغيل المحلي

من داخل هذا المجلد، شغّل:

```powershell
powershell -ExecutionPolicy Bypass -File .\serveur-local.ps1
```

ثم افتح:

```
http://localhost:4173
```

لاختيار منفذ آخر:

```powershell
powershell -ExecutionPolicy Bypass -File .\serveur-local.ps1 -Port 8080
```

ويمكن أيضًا فتح `index.html` مباشرة في المتصفح؛ كل الوظائف تعمل دون خادم.

## النشر على الإنترنت

الموقع ثابت بالكامل، ولا يحتاج إلى قاعدة بيانات أو تسجيل دخول. لنشره بشكل دائم:

1. ارفع المجلد كما هو إلى أي استضافة ثابتة مثل Vercel أو Netlify أو Cloudflare Pages.
2. اجعل مجلد المشروع هو مجلد النشر (Root / Output Directory).
3. لا تحتاج إلى أمر بناء (Build Command)؛ يكفي نشر الملفات الثلاثة.

يمكن أيضًا استخدام وكيل **Picova** داخل Capafy لإنشاء النسخة ونشرها مباشرة.

## تفاصيل التجربة

- **الخطوة 1:** سؤال الموعد، زر «حسناً» الذي يكبر مع كل محاولة، وزر «لا» الذي يهرب عند الاقتراب أو اللمس أو النقر.
- **الخطوة 2:** تقويم عربي تفاعلي، مع منع اختيار الأيام الماضية، وزر «فقط هذا اليوم! ❤».
- **الخطوة 3:** اختيار واحد من: الحنجرة الساخنة، نودلز اللحم، وجبات خفيفة في سوق الليل، شواء، رامن.
- **الخطوة 4:** رسالة حب رومانسية تتضمن التاريخ والطعام المختارين، وزر «اقرأ مرة أخرى» الذي يعيد التجربة إلى البداية.

## ملاحظات

- لا يوجد تسجيل دخول ولا خادم خلفي؛ كل الحالة تعيش في صفحة المتصفح فقط.
- العلامة المائية المطلوبة ظاهرة في الزاوية اليمنى السفلى:
  `تم إنشاء هذه الصفحة بواسطة Picova.`
- يدعم الموقع الهاتف والكمبيوتر، ويحترم إعداد تقليل الحركة في نظام التشغيل.
